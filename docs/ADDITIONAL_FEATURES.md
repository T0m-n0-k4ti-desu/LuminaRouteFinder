# 追加機能の操作

## 再探索と処理の中止

同じ画像・解析範囲では認識結果をメモリーへ保持し、条件変更や候補追加取得時に再利用します。画像内容や範囲を変えると再認識します。「中止」は処理の区切りと探索中のチェックで停止し、設定を変えて再実行できます。OpenCV内部処理の実行中は、その処理が戻るまで停止待ちになります。進行表示は画像確認・盤面認識・種類判定・探索・書き出しを区別します。

## 設定・プリセット・評価方法

「設定・プリセット」から候補数、終了時削除、探索条件、未到達時の優先順位、評価方法、各種類の重みを変更できます。「適用」で確定し、閉じるだけでは未適用の編集を反映しません。名前付きプリセットには探索条件と評価・重みを保存します。同名の保存と削除は確認します。

評価方法は通過数最大、重み合計最大、通過数を優先して同数時に重み、の3つです。重みの初期値は1、負の値も指定できます。ゴール到達を常に優先し、重み合計最大で同値なら通過数を優先します。未到達時の「通過数優先」は、重み付けモードでは選択した経路評価を優先する意味になります。到達段階優先なら段階→経路評価の順です。
