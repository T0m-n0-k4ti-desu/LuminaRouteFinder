# 追加機能の操作

## 再探索と処理の中止

同じ画像・解析範囲では認識結果をメモリーへ保持し、条件変更や候補追加取得時に再利用します。画像内容や範囲を変えると再認識します。「中止」は処理の区切りと探索中のチェックで停止し、設定を変えて再実行できます。OpenCV内部処理の実行中は、その処理が戻るまで停止待ちになります。進行表示は画像確認・盤面認識・種類判定・探索・書き出しを区別します。

## 設定・プリセット・評価方法

「設定・プリセット」から候補数、終了時削除、探索条件、未到達時の優先順位、評価方法、各種類の重みを変更できます。「適用」で確定し、閉じるだけでは未適用の編集を反映しません。名前付きプリセットには探索条件と評価・重みを保存します。同名の保存と削除は確認します。

評価方法は通過数最大、重み合計最大、通過数を優先して同数時に重み、の3つです。重みの初期値は1、負の値も指定できます。ゴール到達を常に優先し、重み合計最大で同値なら通過数を優先します。未到達時の「通過数優先」は、重み付けモードでは選択した経路評価を優先する意味になります。到達段階優先なら段階→経路評価の順です。

## 候補の保存・コピーと通過順の連動

「候補保存」は選択中の候補を元の描画解像度のPNGへ保存します。終了時削除に巻き込まれないよう解析出力フォルダーの外を選んでください。「画像コピー」はWindowsクリップボードへ候補画像を送り、「順序コピー」は候補の条件・通過順をテキストでコピーします。

通過順をクリックすると対応アイコンを強調し、拡大中でもその位置へ移動します。経路画像のアイコンをクリックして通過順へ移動することもできます。候補を変えると強調を解除します。画像保存・コピーには現在の強調も含めます。

## 認識確認と手動補正

「認識確認・補正」は、検証済みの盤面に対して接続・種類・判定指標を表示します。種類や接続を変更し、Undoや元の自動判定への復帰ができます。変更は「確認して再探索」で適用します。画像や範囲を変えると補正は破棄します。

曖昧な接続は診断用に保持しますが、各接続を「あり／なし」で確認するまで探索しません。接続のない段間も明示的な確認が必要です。カーソル遮蔽・下部選択・アイコン欠損など、盤面自体を検証できない画像は補正対象にしません。手動操作と確認の履歴は結果JSONのmanual_correctionsへ記録します。線の交差点をマスとして追加したり、上向き・飛び段の接続を作ることはできません。


## 未到達の原因と条件緩和の比較

「未到達の原因・比較」で、緑＝到達可能、赤＝除外・通行不可、黄＝最深段、灰＝到達不可の画像を表示します。これは現在の接続データと条件の到達範囲で、唯一の原因や最小の解除条件を保証する表示ではありません。途中経路の解析ではdiagnostic.pngと結果JSONにも診断を保存します。

比較は現在の条件、連続禁止解除、除外を1種類ずつ解除、すべての除外・連続禁止解除を対象にします。評価方法・重みは維持します。「比較を中止」で停止できます。比較するだけでは設定を変更せず、選択行を「適用して再探索」で反映します。種類不明で制約を評価できない場合や、比較後に画像・補正が変わった場合は適用しません。

## PRの取り込み順

認識セッション・キャンセル → 設定・プリセット・重み → 保存・コピー・通過順連動 → 認識確認・補正 → 未到達診断・条件緩和比較、の順です。各PRは直前のブランチをbaseにしています。
